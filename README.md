**UVW : XYZ와 같은개념
원래 3DS 4.0 까지는 모든것을 XYZ로 표현했으나 UVW는 워크 스테이션 소프트웨어 게임들이 맵핑을 할 때 알파벳에서 XYZ 대신의 그 앞의 3자인 UVW를 사용하면서 MAX에서 사용하게 된것.

UV = 3D모델의 2D 전개도 ( 꼭 맞는 옷을 입히는 것과 같음 )

UV 맵이란 텍스쳐링을 위한 3D모델의 표면으로, 펼쳐놓은 전개도(UV) 라고 할 수 있다.

3D모델링에서 UV 언랩은 전개도를 만드는 과정.

UV맵핑은 만들어진 전개도를 3D모델에 포장하는 과정.

UV가 없는 모델에 메터리얼을 적용하는 것이 3D모델링에 페인트를 부어서 만든것이라면
UV가 있는 모델에 메터리얼을 적용한다는 것은 딱 맞는 종이포장지로 포장을 하는 개념

UV가 있으면 각면에 대한 텍스쳐를 훨씬 자유롭게 컨트롤 가능
->보다 리얼하고 디테일한 결과물을 만들 수 있다.

UV 편집창 : 편집창에 보이는 이 공간(타일)이 U, V축을 지닌 2D 공간임

3D공간에서 이미 X, Y, Z 축을 사용하기 때문에 2D로 펼치는 전개도에서는 U와 V축을 사용하게 됨

잘 펼쳐진 정육면체의 UV, 초록색선 = 절개선 (seam)

잘 펼쳐졌는지는 체크무늬패턴 을 입혀서 모든면에서 체크무늬가 올바른 방향과 밀도로 들어갔는지 확인

패턴이 왜곡이 생기거나 문제가 생기면 수정을 한다.

***유의사항***
잘 보이지 않는 곳에 절개선을 넣는다
다른 파트와 겹쳐서 가려지는 부분에  절개선을 넣는다
만약 카메라시야에 절개선이 들어올 수 밖에 없다면 시선이 집중되는 위치는 피하는것이 좋다

언랩핑 - 공간이 한정 됨.
선택과 집중이 중요.
공간을 알뜰하게 사용해야한다.
남는 공간없이 채워서 해상도 낭비가 없게 해야한다.

스캔라인 랜더러
맥스의 기본렌더링 방식은 스캔라인
맥스의 랜더러를 스캔라인 렌더러
대부분의 소프트웨어는 빠른 렌더링 속도 때문에 스캔라인 렌더러를 사용.
렌더러는 여러 종류가 있음.
스캔라인은 질이 가장 낮은 반면 속도는 비교할 수 없이 빠름.
